# plasma/

Visual Nullyz para KDE Plasma 6 (#8), empacotado em `packages/nullyzos-desktop-kde`:

| Arquivo | O que é |
|---|---|
| `look-and-feel/org.nullyzos.desktop` | tema global: barra em cima (N, menu global, bandeja, relógio), dock flutuante, tela de abertura |
| `gerar.py` | gera `NullyzEscuro.colors`, `NullyzClaro.colors` e as cores do Konsole de `branding/tokens.json` |
| `xdg/` | padrões do sistema (`/etc/xdg`): fontes Geist, botões das janelas à esquerda, desfoque, Konsole |
| `konsole/Nullyz.profile` | perfil do Konsole (Geist Mono, margens) |
| `nullyzos-kde-primeiro` | no primeiro login aplica o tema global inteiro (uma vez) |
